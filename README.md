# Portfólio de Desenvolvimento Sob Medida & Automações

Landing page de alta conversão apresentando soluções de software sob medida, motores de regras tributárias (ex: Calculadora CBS/IBS), automações empresariais e dashboards.

---

## 🚀 Como Publicar no GitHub Pages

### 1. Criar o Repositório no GitHub
Na sua conta do GitHub (`andrefigura37-del`):
1. Acesse: https://github.com/new
2. No campo **Repository name**, digite: `software-sob-medida` (ou o nome de sua preferência).
3. Deixe marcado como **Public**.
4. Não marque as opções de adicionar README, .gitignore ou License (já temos tudo configurado aqui).
5. Clique em **Create repository**.

---

### 2. Comandos para Enviar o Código (Terminal dentro desta pasta)

Abra o terminal nesta pasta (`C:\Workspace\Projetos\Portifolio`) e rode:

```bash
# 1. Iniciar o Git
git init

# 2. Adicionar os arquivos
git add .

# 3. Criar o primeiro commit
git commit -m "feat: landing page portfolio de software sob medida"

# 4. Definir a branch principal
git branch -M main

# 5. Conectar com o seu repositório no GitHub (substitua o nome se mudou)
git remote add origin https://github.com/andrefigura37-del/software-sob-medida.git

# 6. Enviar para o GitHub
git push -u origin main
```

---

### 3. Ativar o GitHub Pages

1. Vá em **Settings** > **Pages** no repositório.
2. Em **Build and deployment** > **Source**, selecione: `Deploy from a branch`.
3. Selecione a branch `main` e a pasta `/ (root)`.
4. Clique em **Save**.

Em cerca de 1 a 2 minutos o site estará online no link:
👉 `https://andrefigura37-del.github.io/software-sob-medida/`
